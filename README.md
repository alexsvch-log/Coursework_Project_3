# Поррамма поиска вакансий

Программа собирает данные о компаниях и вакансиях с сайта hh.ru, записывает их в таблицы в БД PostgreSQL, загружает полученные данные в созданные таблицы и выдает аналитику по собранным данным в соответствии с выбранным запросом.

### Требования
Для запуска и разработки проекта вам понадобятся:

* **Python 3.14+** (проект использует современные возможности типизации)
* **Poetry** — инструмент для управления зависимостями и виртуальными окружениями.

### Настройка окружения и зависимостей
Управление зависимостями осуществляется через Poetry (без использования requirements.txt).

**1. Клонирование репозитория**
```bash
git clone https://github.com/alexsvch-log/Coursework_Project_3.git
```
**2. Установка зависимостей**

```bash
poetry install
```
**3. Запуск и активация окружения**

Активация виртуального окружения: 
```bash
poetry shell
```
Запуск скриптов напрямую:
```bash
poetry run python main.py
```

### Инструменты разработки (Linting)
В проекте настроена автоматическая проверка качества кода (`black`, `flake8`, `mypy`). Все конфигурации линтеров объединены в файле `pyproject.toml`.

Если вы планируете использовать линтер flake8, то рекомендуется установить плагин командой 
```bash
poetry add flake8-pyproject
```
Файл .flake8 в проекте отсутствует.

В случае, если вы решите установить линтеры - black, flake8, mypy - в корне проекта расположен файл lint.bat. При выполнении команды: .\lint на терминале запускаются все линтеры сразу.

**1. Установка инструментов:**
```bash
poetry install --with lint
```
**2. Быстрый запуск всех проверок (Windows):**
```bash
.\lint
```

### Демонстрация работы сценария:
ШАГ 1. **Выбор списка компаний:** Скрипт выводит два набора компаний и предлагает выбрать один:
Выберите список компаний, вакансии в которых вы хотите найти:
Если "1, 2, 3, 4, 5" введите 1
Если "11, 12, 13, 14, 15" введите 2
==> 1
При выборе 1 скрипт читает вакансии из локального файла hh_vacancies.json, при выборе 2 — пытается получить данные через сетевой адаптер HeadHunter (hh_random_api.json) с имитацией запроса к сайту, либо получает данные из резервного файла hh_random_api.json.
ШАГ 2. **Меню действий** После загрузки данных скрипт выводит меню:
1. Список всех запрошенных компаний и количество вакансий у каждой компании
2. Список всех вакансий с дополнительной информацией
3. Средняя зарплата по всем вакансиям
4. Список всех вакансий, у которых зарплата выше средней
5. Список всех вакансий по ключевому слову в названии
==> 1
Пример вывода (пункт 1)
Статистика вакансий по компаниям:
 - VK: 12 вакансий
 - Газпром: 7 вакансий
 - Тинькофф: 0 вакансий
Пример вывода (пункт 2)
Компания: VK | Вакансия: Python-разработчик | ЗП: 150000-250000 руб. | Ссылка: https://hh.ru/vacancy/123456
Пример вывода (пункт 3)
Вакансия: Python-разработчик | Средня ЗП: 200000 руб.
Пример вывода (пункт 4)
Вакансии с зарплатой выше средней:
Компания: VK | Вакансия: Python-разработчик | Зарплата: 150000-250000 руб. (Средняя зп для вакансии: 200000 руб.) | Средняя по всем предложениям: 145000 руб. | Ссылка: https://hh.ru/vacancy/123456
Пример вывода (пункт 5)
При выборе пункта 5 скрипт запрашивает ключевое слово (по умолчанию Python):

Производится поиск вакансий по ключевому слову 'python':

### 🛡️ Отказоустойчивость (Design for Failure)
Программа с помощью модуля api_adapter работает по принципу "сеть → локальный резерв":
Сначала выполняется запрос к API HeadHunter с таймаутом 5 секунд.
Если запрос успешен и содержит валидную структуру items, данные возвращаются напрямую.
При любой ошибке — сетевой сбой, некорректный формат ответа или исключение при обработке — метод переключается на загрузку данных из локального JSON-файла (data/<filename>).
Управление режимом через параметр force_local:
force_local	Поведение
True	Сразу читает локальный файл, сетевой запрос не выполняется
False	Сначала пробует сеть, при сбое читает локальный файл
Каждая ситуация логируется в консоль:
Сетевой запрос к API не удался. Причина: <текст ошибки>
Успешно загружен резервный файл: data/hh_vacancies.json
Предупреждение: Локальный резервный файл не найден по пути: data/hh_vacancies.json
Если недоступны и сеть, и локальный файл, метод возвращает пустой список [] — падения приложения не происходит.
